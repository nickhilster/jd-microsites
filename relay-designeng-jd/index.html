The bridge

How design becomes production in my practice.

SystemTokens, variables and components defined in Figma as the source of truth.
SpecEach build starts as a written spec and project instructions — the design intent, made explicit.
BuildProduction front-end in HTML, CSS and JavaScript; React and TypeScript codebases built with coding agents under my direction.
ReviewEvery diff read line by line. The agent types; the architecture and the quality bar are mine.
VerifyTest suites gate the release — including, for LTB Buddy, checks run against a live government portal.
Relay's own nice-to-haves name AI tools and workflows. Mine are not a novelty: they are the production line, with a human holding the standards.
