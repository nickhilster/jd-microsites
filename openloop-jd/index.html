Tokens in tiers, components with names, conventions in writing.

An excerpt of the actual structure behind this page and the product surfaces it styles — the same documentation a new designer, or a new agent, reads on day one.

Token tiers

Primitive
--paper #fffaf0 · --ink #302923 · --gold #e9b642 · --red #a53e2e — raw values, never used directly in components.
Semantic
surface / text / muted / accent / border — meaning assigned to primitives; theming happens by re-pointing this tier, which is how one foundation carries multiple product brands.
Component
sitebar · hero · evidence-card · metric-row · callout · cta-band — named, documented, versioned; each with states, dos and don'ts.
Status labels
Parenthesised, uppercase, semantic colour — (LIVE), (LIVE PRACTICE) — so state is scannable by a person and parseable by an agent.
